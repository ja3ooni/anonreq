# Milestone v2.0 Roadmap — Enterprise & Deployment Moat

**Shipped:** 2026-08-03  
**Status:** ✅ 100% Complete (5/5 phases, 12/12 plans)

---

## Phases

### Phase 28: High Availability Cache & Resilience
- **Goal**: Resilient, HA-aware Valkey connection caching logic that is fail-safe during reelection.
- **Plans**:
  - `28-01`: Implement Valkey Sentinel & Cluster connection factories in CacheManager (Completed 2026-07-12)
  - `28-02`: Implement exponential backoff retries with fail-closed security guards for reelection failovers (Completed 2026-07-12)

### Phase 29: Secure Configuration & Secrets Management
- **Goal**: Safe, dynamic secrets retrieval and hot-reloading from HashiCorp Vault / Cloud KMS without env or disk persistence, including secure rotation buffering and logs redaction.
- **Plans**:
  - `29-01`: Integrate hvac and dynamic secret retrieval from Vault/cloud KMS (Completed 2026-07-12)
  - `29-02`: Implement watchdog volume monitor and config hot-reload (Completed 2026-07-12)
  - `29-03`: Implement log formatter secret redaction and rotation buffer grace window (Completed 2026-07-12)

### Phase 30: Enterprise Authentication & RBAC
- **Goal**: Secure administrative and gateway access using OIDC JWT signature verification, predefined enterprise roles, and ingress-forwarded mTLS validation.
- **Plans**:
  - `30-01`: Replace static API-key principal construction with authlib-based OIDC verification and local JWKS caching (Completed 2026-07-13)
  - `30-02`: Normalize existing RBAC dependencies to enterprise roles and apply consistently to gateway and admin access (Completed 2026-07-13)
  - `30-03`: Implement mTLS client certificate verification middleware (Completed 2026-07-13)

### Phase 31: Multi-Tenant Segregation & Isolation
- **Goal**: Rigid request namespacing, tenant-scoped cache partitioning with dynamic KMS encryption, and tenant-scoped logging/metrics.
- **Plans**:
  - `31-01`: Implement TenantContextMiddleware and migrate existing tenant-scoped cache usage to validated Valkey prefix (Completed 2026-07-18)
  - `31-02`: Implement dynamic key-based encryption for cached token mappings (Completed 2026-07-18)
  - `31-03`: Implement tenant-scoped logging interceptors and labeled Prometheus metrics (Completed 2026-07-18)

### Phase 32: Kubernetes Deployment & Scaling
- **Goal**: Package the enterprise-grade HA, multi-tenant, and secret-managed gateway into an official Helm v3 deployment.
- **Plans**:
  - `32-01`: Create Helm v3 chart with replica controls and HPA / anti-affinity rules (Completed 2026-08-03)
